# viz-kit

Блоки для вставок в чате Claude. Модель пишет только данные, `viz.js` рисует и считает сам. Один файл, зависимостей нет.

```html
<script src="https://cdn.jsdelivr.net/gh/nlysiuk/viz-kit@1.0.0/viz.js"></script>
<v-panel>
  <v-share label="Купили после пробной версии" k="5" n="32">Выборка мала, решать рано.</v-share>
  <v-item heading="Переписать первое письмо" tag="Высокий приоритет" tone="good">Два дня работы.</v-item>
</v-panel>
<v-photos>
  <v-photo src="data:image/webp;base64,…" heading="Обложка А" tag="Стоит пробовать" tone="good">Тёплый свет.</v-photo>
</v-photos>
```

## Теги

| Тег | Атрибуты | Что делает |
|---|---|---|
| `v-panel` | нет | Рамка для строк `v-share` и `v-item` |
| `v-share` | `label`, `k`, `n` | Доля k из n. Текст тега идёт после процента и интервала |
| `v-item` | `heading`, `tag`, `tone` | Строка с пилюлей-вердиктом |
| `v-photos` | нет | Ряд фото, показывает не больше двух |
| `v-photo` | `src`, `heading`, `tag`, `tone` | Фото с подписью. `src` только `data:image/…` |

`tone` задаёт цвет и иконку пилюли: `good`, `info`, `calm`, `bad`.

## Расчёты

`v-share` выбирает форму по `n`: до 40 квадраты, до 2000 мелкая сетка, дальше полоса. При `n` меньше 200 он считает интервал Wilson 95% и рисует его на шкале 25, 50 или 100%. Проценты пишет по-русски: `15,6%`.

## Ошибки в данных

На месте блока появляется красная строка, например `v-share: k больше n (k=30, n=27)`. Исправь данные и отправь вставку заново.

## Оформление

Цвета идут из токенов приложения (`--text-primary`, `--surface-1` и других) с запасными значениями. Шрифты Onest и JetBrains Mono грузятся с Google Fonts, при сбое работает шрифт приложения.

